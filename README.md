# Diabetes Prediction using Machine Learning

This project predicts whether a person is likely to have diabetes
using a Support Vector Machine (SVM) machine learning model.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Support Vector Machine (SVM)
- Joblib
- Streamlit

## Input Features

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

## Output

- 0 → No Diabetes
- 1 → Diabetes
